## 다크모드 토글 아이콘 깜빡임 (재확인 필요)

페이지 이동 직후 순간적으로 깜빡이거나(리마운트 시) 잘못된 아이콘으로 고정되는 문제. 여러 번 시도해 고쳤으나(`ThemeToggle.tsx`), 사용자가 마지막으로 확인했을 때도 완전히 해결됐는지 재확인 전이었음.

최신 구현은 "마운트 전엔 아이콘을 그리지 않다가 마운트 직후에만 실제 DOM 상태로 확정"하는 방식(`mounted` state 게이팅).

재현되면 다음 순서로 브라우저 콘솔에서 직접 확인하며 디버깅했음 — 같은 방식 참고:
1. `document.documentElement.classList`
2. `localStorage.getItem('theme')`
3. `getComputedStyle(...).backgroundColor`
