# 이슈 목록

CLAUDE.md의 "알려진 이슈 / 미해결"에서 분리한 상세 기록. 관련 작업을 시작하기 전에 확인할 것.

## 포트폴리오 버튼 미동작 (의도적 보류)

UI만 있고 실제 동작은 없음. 알림/설정 버튼은 계획도 없이 UI만 있던 죽은 기능이라 헤더에서 제거했지만(관리자 인증 mock 없앤 것과 같은 맥락), 포트폴리오는 유지하기로 함 — **블로그 자체가 완성된 뒤에 작업할 예정**이라 지금은 그냥 버튼만 있는 상태.

## 조회수 미구현

아직 구현 안 됨. 원래 와이어프레임엔 "로그인 시 수정 버튼" 같은 목표가 있었으나, 콘텐츠를 노션에서 쓰기로 하면서 **더 이상 필요 없어졌을 가능성이 큼**(수정도 노션에서 하면 되므로) — 이 부분 와이어프레임 자체를 재검토할 것.

좋아요는 별도로 안 만들기로 함 — giscus를 `reactionsEnabled="1"`로 붙이면서 댓글 스레드에 이미 리액션(👍 등)이 달려서, 굳이 익명 카운트용 백엔드를 따로 만들 필요가 없어짐.
